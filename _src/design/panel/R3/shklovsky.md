Critic: Provocateur (Shklovsky), R3

Anchor used: Shklovsky, "Art as Technique": defamiliarization. A familiar object made strange so that perception is prolonged; the device must be felt, not recognized and skipped.

Observed: In the 1280 shots the dimmed jack-o'-lantern stops reading as a logo. Dark o'clock lights only the moon eye. Candy math lights only the wrapped candy. Haul splitter lights the rib seams. Stencil lights BOO. Because the rest of the skin is dark, the eye goes to the one lit part, and the same pumpkin reads differently on each page. The front page pumpkin is fully lit, so the band version reads as a dimmed state of it, which is the contrast that helps. Weakest case: Candy math, where the small candy glows only modestly against the dim skin. It is still the brightest thing in the lantern.

Verdict: PASS

Requested change: none

Statement of meaning: One lantern, one lit part: the page you are on is the part that glows.

Critic question: Will a first-time reader, with no front-page memory, still name the lit part as "this page" and not as decoration?
